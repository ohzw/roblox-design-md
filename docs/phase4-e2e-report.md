| 入力 | 内容 | チェックリスト充足 |
|---|---|---|
| playmenu (1900×573, クロップ) | ロビーメニュー: プライマリCTA+アイコンボタン列 | ボタン複数 ✓ |
| knobs (696×560) | ゲーム内ショップウィンドウ（カード・価格ピル・入力欄・閉じる） | ウィンドウ ✓ |
| hotbar (738×140, クロップ) | HUDホットバー（スロット・キー番号・使用量メーター） | HUD **部分のみ**（フル欠落→ギャップ申告テスト） |

対極性: 太枠→細枠(2px)、不透明→半透明ガラス、彩度全開→ダーク+2アクセント系統、
ベベル/スカッシュ→影ゼロ/明度リフト、単一ファミリー→3書体ボイス。
