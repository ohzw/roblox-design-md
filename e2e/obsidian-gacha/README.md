# Obsidian Gacha — preview implementation

react-lua implementation of `design-md/obsidian-gacha/DESIGN.roblox.md`,
generated by the `designmd-to-react-lua` skill. Renders the full catalog
preview set as UI-Labs stories so the entry can be captured in Roblox Studio.

## Render & capture

This tree reuses `preview-place/`'s wally `Packages` (via the project file's
relative `$path`), so no separate `wally install` is needed.

```sh
# from repo root
argon serve e2e/obsidian-gacha/default.project.json
# open the served place in Studio, open the UI-Labs plugin, pick the
# "Obsidian Gacha" storybook, then Play + screenshot each story.
```

Capture these stories into `design-md/obsidian-gacha/previews/` (the site's
publish gate reads that folder):

The MCP visual-QA loop (play → mount story → screenshot → assert) is in

## Notes / caveats

- **Studio MCP was offline during generation**, so no in-engine visual/numeric
  QA ran. Syntax (`luau`), banned-API, and hex-outside-Theme checks all pass;
  the in-engine loop still needs to run before the previews are trustworthy.
- **Image assets** are reused from the catalog's arbitrated canonical set
  (`Theme.assets`); re-verify each renders (not blank) via `ImageLabel.IsLoaded`
  in the capture. The gem/Robux/sparkle slots reuse diamond/coin icons recolored
  (no arbitrated asset for those exact glyphs); the Roll die is procedural.
- **Backdrop blur** (the taste's signature transition) is implemented on
  `Lighting` (`Window.luau`) and is visible over the live 3D world; in a
  UI-only story the opaque story backdrop hides the 3D view, so the blur runs
  but is not visible in the still — expected.
- **Shop grammar:** the six standard-showcase items use this taste's rarity-CARD
  grammar (fill + brackets + name recolor to tier) with an in-card buy pill; one
  signature `BannerOffer` sits above as a featured promo. The banner-offer +
  aura-grid are both real shop surfaces in the source.
- One component, `IconTile`, fulfils the DESIGN.md's `side-button` + `button-icon`
  (prop-branched anatomy). `ActionButton` fulfils `button-primary` / `-secondary`
  / `-danger` / `-buy` via its `variant`.
